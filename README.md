# Sistema de Gestión y Distribución de Pólizas

Sistema desarrollado para la materia de Arquitectura de Software 2026-II.

El proyecto consiste en una solución para la gestión y distribución de información de pólizas de seguros mediante una API REST, permitiendo consultar y actualizar información proveniente de un sistema remoto.

**Materia:** Arquitectura de Software

## 🎯 Objetivo del proyecto

Desarrollar una solución de software capaz de distribuir información de pólizas de seguros mediante una API REST y mantener consistente la información entre el sistema remoto de origen y el sistema de tránsito y distribución.

La solución permitirá realizar consultas y actualizaciones de información de pólizas bajo demanda.
